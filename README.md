# JOGO DA COBRA🐍

Objetivo é desenvolver um jogo 2D utilizando Canvas, HTML e JavaScript sem esquecer de aplicar os conceitos estudados, o jogo de deve estar funcionando, e deve haver o uso de Git e GitHub.
Objetivo do jogo é você guiar a cobra🐍 até a maçã🍎 e come-la, toda vez que você come a fruta a cobrinha aumenta e a sua pontuação aumenta, porém se você colide nas bordas é GAME OVER.

# EXIGÊNCIAS🗒️

 •  Polimorfismo, utilizar cores diferentes para a cobra e para a comida.✅

 •  Ao colidir nas bordas é GAME OVER.✅

 • Implementar Pontuação.✅

 • Aumentar o tamanho da cobra toda vez que come uma fruta.❌

 •  Armazenar cada pedaço da cobra.❌
 
 • Quando a cobra bate em si mesmo é GAME OVER.❌

# GITHUB🐱

 • Criar um Repositório Público✅

 • Deve haver no mínimo 2 branches.✅

 • Sempre realizar commits com mensagens✅


# COMO JOGAR🎮

Use W, S, D, A, para movimentar a cobra e chegar até a maçã, toda vez que você come a sua pontuação vai aumentar, e se você enconstar nas bordas você perde e é GAME OVER.
